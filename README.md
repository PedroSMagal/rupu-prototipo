# rupu-prototipo
Protótipo mobile do app do Restaurante Universitário da UESC (R.U.P.U.): cardápio do dia, fila, fichas restantes, timer de abertura, carteira com QR de uso único, enquetes e login por matrícula. Feito em HTML, CSS e JS puro para a disciplina de IHM, aplicando Shneiderman, Nielsen, teoria das cores e acessibilidade.
